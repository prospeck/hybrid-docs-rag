NORTHSTAR PUBLIC API OPERATIONS

AUTHENTICATION
API clients use OAuth 2.0 client credentials. Access tokens expire after 60 minutes. Production client secrets are displayed once at creation and must be stored in the approved secrets manager. The gateway returns AUTH-4017 when a token has the wrong audience.

RATE LIMITS
Standard tenants receive 600 requests per minute. Enterprise tenants receive 3,000 requests per minute. The response headers X-RateLimit-Limit, X-RateLimit-Remaining, and X-RateLimit-Reset describe the active window. Clients should use exponential backoff with jitter after HTTP 429.

IDEMPOTENCY
POST /v1/payments and POST /v1/refunds require an Idempotency-Key header. Keys are retained for 24 hours. Reusing a key with a different request body returns HTTP 409 with error IDEMPOTENCY_MISMATCH.

PAGINATION
List endpoints use opaque cursor pagination. The maximum page size is 200 and the default is 50. Cursors expire after 15 minutes and must not be parsed or modified by clients.

WEBHOOKS
Webhook deliveries are signed with HMAC-SHA256 in X-Northstar-Signature. Consumers must verify the raw request body and reject timestamps older than five minutes. Failed deliveries retry for 24 hours using exponential backoff.
